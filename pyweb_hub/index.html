Welcome to PyWeb!

This is the official Hub for PyWeb, demonstrating the capabilities of our Python-based browser engine.

What is PyWeb?

PyWeb is a proof of concept project that aims to build a web browser and ecosystem entirely from scratch using Python, bypassing JavaScript entirely.

Features Showcase

  • Python-based DOM Engine
  • Native Python Script Execution
  • Built-in APIs: fetch, localStorage, history, navigator
  • Custom UI rendering using Tkinter
