The PyWeb Client

The PyWeb client is a custom-built browser designed to render HTML and execute embedded Python.

Current Implementation

  • Browser UI: Built using Tkinter, providing basic navigation controls (Back, Forward, Reload, Address Bar).
  • Render Engine: Parses HTML and translates it into Tkinter widgets. Handles block and inline elements (`div`, `p`, `button`, `input`).
  • Script Engine: Extracts <script type="text/python"> tags and executes them in a sandboxed Python environment with injected Window and Document variables.
  • Router: Supports multiple schemes including app://, file://, http://, and relative://.

Future Implementations

  • Advanced Network Model: Full socket handling, TLS/SSL communications, native DNS resolution, and binary resource fetching.
