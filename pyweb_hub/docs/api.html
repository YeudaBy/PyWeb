The PyWeb API

These are the modules exposed to developers writing PyWeb applications.

Current APIs

  • Document & DOM: Document.get_element_by_id, element.add_event_listener, element.set_text. Elements follow an OOP hierarchy.
  • Network (fetch): from pyweb_api import fetch - Make HTTP requests and get JSON or text responses.
  • LocalStorage: from pyweb_api import localStorage - Use get_item and set_item to persist data.
  • History: from pyweb_api import history - Manage navigation state using push_state.
  • Navigator: from pyweb_api import navigator - Read client environment details.
  • Console: Window.console.log, warn, error - Log outputs to the browser's developer console.

Future APIs

  • Cookies: Full integration with HTTP state management.
  • WebSocket: Bi-directional communication API for real-time apps.
  • Media API: Controlling media playback programmatically.
  • Worker API: Background Python threading for offloading heavy tasks from the main UI thread.
  • Advanced Request/Response: Exposing full HTTP Header manipulation to developers.
