Security Considerations

WARNING: You should NOT use this program on your computer to browse untrusted sites.

PyWeb currently suffers from significant security limitations:

  • No Sandbox: Python does not have an actual sandbox for executing untrusted code. Scripts running on a webpage have access to your local Python environment and potentially your filesystem!
  • XSS: Standard Cross-Site Scripting vulnerabilities exist due to naive rendering of strings in the DOM.

These will be tackled eventually, but are currently major blockers for real-world usage.

Development Roadmap

We are building the browser one component at a time. The current focus is on a working POC that can render interactive HTML pages.

  • Phase 1 (Current): POC rendering, inline Python scripts, basic network/DOM APIs.
  • Phase 2 (Next): Full CSS parser, complex layout engine, WebSockets.
  • Phase 3 (Future): JavaScript transpiler/translator, Security sandbox integration, pycakge, PyWebAct.
