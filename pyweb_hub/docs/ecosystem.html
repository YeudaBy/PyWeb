The PyWeb Ecosystem

A programming language alone does not make a web platform. The web is defined by its massive ecosystem of packages, frameworks, and tools.

Current Ecosystem

  • PyWeb Hub: The central documentation and example website that you are currently browsing. It is designed to dogfood the PyWeb API and validate its functionality.

Future Ecosystem Initiatives

  • pycakge (Package Manager): A package manager tailored for PyWeb applications. Instead of NPM, developers will use pycakge to share components, UI libraries, and utility functions written in pure Python.
  • PyWebAct: A React-like framework built natively for PyWeb. It will introduce functional components, hooks (e.g., use_state, use_effect), and a virtual DOM diffing engine to make writing complex UIs in PyWeb robust and predictable.
