What is PyWeb?

PyWeb is a proof of concept (POC) project to try to build the web world from scratch, with Python.

If you want to build for the web today, you have to do it with JavaScript. PyWeb challenges this paradigm by introducing a native Python browser and ecosystem.

Philosophy

  • Use JavaScript naming conventions where appropriate (e.g., document.get_element_by_id), but keep Python PEP 8 style.
  • Type everything using Python hint typing.
  • Rely heavily on the OOP paradigm.
  • Write clean and self-explanatory code.

Capabilities Overview

The PyWeb ecosystem is divided into several main components:

  • PyWeb Client: The browser client that renders HTML and executes Python script tags.
  • PyWeb API: The library developers use to write dynamic websites (DOM, fetch, history, etc.).
  • PyWeb Hub: The website you are browsing right now.
  • Future Ecosystem: Package managers (pycakge) and frameworks (PyWebAct).
