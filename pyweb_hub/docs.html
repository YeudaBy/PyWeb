Documentation

PyWeb supports standard HTML elements and Python-based DOM manipulation through inline scripts.

1. DOM API

You can interact with elements using standard identifiers and methods.

  • Document.get_element_by_id(id): Fetch an element by its ID.
  • element.set_text(text): Replace text content.
  • element.add_event_listener(type, callback): Bind interactions like "click".
  • element.attrs.get(key): Access HTML attributes.

2. Network (fetch)

Perform HTTP requests natively using Python's urllib underneath.

  • from pyweb_api import fetch
  • response = fetch("https://api.example.com")
  • data = response.json()

3. Local Storage

Persist data across your PyWeb browsing sessions.

  • from pyweb_api import localStorage
  • localStorage.set_item("key", "value")
  • value = localStorage.get_item("key")

4. Navigator

Access information about the environment.

  • from pyweb_api import navigator
  • agent = navigator.user_agent

5. History

Manipulate navigation states.

  • from pyweb_api import history
  • history.push_state(state, title, url)
